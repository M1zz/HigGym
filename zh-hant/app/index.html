不止於閱讀的設計學習

好的 UI/UX 是由許多小決定堆疊而成的。與其只讀，不如親手使用一個故意違反規範的介面，寫下哪裡感覺不對，再與規則對照。 應用程式包含 23 節課程、68 個帶註解的條目、100 篇常見失誤、7 條原則、5 個練習室和 396 道測驗題。全部內容提供繁體中文、英語、日語和韓語。

每節課分五步

  1. 動手試試：以實際大小開啟一個示例應用程式並領取任務。你在這裡使用的介面是故意違反規範的。
  2. 寫下來：在看到答案之前，先記下哪裡讓你覺得奇怪。
  3. 看原因：你的筆記與規則並排顯示，還有這個決定、背後的理由，以及把它顛倒後會出什麼問題。
  4. 對比：在同一個位置來回切換出問題的介面和改好的介面，看看差別。
  5. 寫下學到的：留下一句下次能用上的話。筆記可以複製為文字，也可以匯出為 Markdown 檔案。

三個標籤頁

  • 學習：由 23 節課程組成的課程，每節講一個設計決定，例如底部撰寫按鈕、滑動刪除、工具列項目分組、搜尋的位置、該用幾個標籤。
  • 筆記：你在課程中寫下的所有內容，匯集在一處。
  • 資料：以示意圖瀏覽 68 個條目，包括工具列、文字、標籤列、工作表和選單。輕點圖中的任意部位，就能看到它的規則和理由，每個條目還可以開啟一個能執行的示例。
