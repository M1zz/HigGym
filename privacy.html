개인정보처리방침

앱 디자인 실습 (iOS) · 시행일 2026년 10월 20일

앱 소개 · 지원 페이지

요약

앱 디자인 실습은 개인정보를 수집하지 않습니다. 회원가입이 없고, 광고·외부 분석·추적 도구를 쓰지 않습니다. 진도와 노트는 기기 안에만 남습니다. 앱을 몇 명이 쓰는지 알고 오류를 고치기 위해 익명 사용 통계와 오류 보고만 보냅니다.

1. 수집하는 정보

개인정보는 수집하지 않습니다. 앱에는 제3자 SDK, 광고 식별자(IDFA) 사용, 위치·연락처·사진·카메라 접근이 없습니다. 기기 밖으로 나가는 것은 아래 ‘익명 사용 통계’에 적은 항목과, 사용자가 직접 보내기로 한 의견(3번)뿐입니다.

익명 사용 통계

앱을 몇 명이 쓰는지 알고 오류를 고치기 위해, 다음 익명 통계를 Apple iCloud(CloudKit)로 보냅니다. 개발자만 읽습니다.

  • 설치할 때 만든 무작위 ID (사용자·Apple ID·기기·다른 앱과 연결되지 않으며, 다시 설치하면 바뀝니다)
  • 앱 버전, iOS 버전, 지역·언어 설정
  • 앱을 연 횟수와 앱을 연 날, 설치한 날짜와 설치 후 지난 날수
  • 앱이 멈추거나 종료된 오류 보고 (앱 버전, iOS 버전, 기기 종류, 오류의 기술 정보)

이름, 연락처, 위치, 학습 노트나 퀴즈 기록 같은 사용자가 만든 내용은 포함하지 않습니다. iCloud에 로그인되어 있을 때만 보냅니다. 이 통계는 개발자가 직접 만든 공용 라이브러리(LeeoKit)가 보내며, 제3자에게 넘기지 않습니다.

2. 기기 안에만 저장되는 정보

학습을 이어서 할 수 있도록 다음 내용을 사용자의 기기 안에만 저장합니다. 개발자를 포함해 누구에게도 전송되지 않습니다.

  • 레슨 진도와 레슨에서 직접 적은 학습 노트
  • 퀴즈 정답·오답 기록, 방문한 실습, 체크한 실수 항목

이 정보는 앱을 삭제하면 함께 지워집니다. 기기 백업(iCloud 백업 등)을 켜 두었다면 Apple의 백업 정책에 따라 백업에 포함될 수 있습니다.

3. 사용자가 직접 내보내는 경우

  • 복사, 학습 노트나 예제 코드를 복사하면 기기의 클립보드에 들어갑니다.
  • 공유, 학습 노트를 마크다운 파일로 내보낼 때 iOS 공유 시트가 열립니다. 어디로 보낼지는 사용자가 고르며, 앱은 그 이후의 처리에 관여하지 않습니다.
  • 의견 보내기, 설정의 ‘피드백 보내기’에서 보내기를 누르면 직접 쓴 글과 앱 버전·iOS 버전·기기 종류가 Apple iCloud(CloudKit)로 전송되어 개발자만 읽습니다. 이름이나 연락처는 묻지 않으며, 답장은 앱 안에서 확인합니다.
  • 메일·인스타그램 문의, 설정의 문의 행을 누르면 기기의 메일 앱이나 Instagram이 열립니다. 그 뒤의 처리는 각 서비스의 방침을 따릅니다.

4. 인앱 결제

Pro 구독과 평생 이용권의 결제는 Apple이 App Store에서 처리합니다. 앱과 개발자는 카드 번호나 결제 정보를 받지 않습니다. 앱은 Pro가 열려 있는지를 판단하기 위해 Apple이 기기에 보내는 구매 기록만 확인하며, 이 확인 결과는 기기 안에만 남습니다.

5. 외부 링크

근거 자료 링크(Apple Developer 문서, 참고 블로그 등)를 누르면 Safari 등 기기의 브라우저에서 열립니다. 해당 사이트의 정보 처리는 각 사이트의 방침을 따릅니다.

6. 아동의 개인정보

앱은 어떤 연령의 사용자로부터도 개인정보를 수집하지 않습니다. 익명 사용 통계도 누구의 것인지 알 수 없습니다.

7. 방침의 변경

앱이 정보를 다루는 방식이 바뀌면 이 페이지를 먼저 고치고 시행일을 새로 적습니다.

8. 문의

개인정보와 관련한 질문은 leeo@kakao.com 또는 GitHub Issues에 남겨 주세요.
